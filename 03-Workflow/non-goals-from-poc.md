# Non-Goals Carried From Legacy PoC

Use this file to explicitly reject legacy decisions that should not be rebuilt.

## Rejected by default

1. Hidden coupling between modules.
2. Unclear folder ownership.
3. Implicit side effects during routing.
4. Feature-first expansion before testable core.
5. Complex configuration before baseline behavior exists.

## Decision log format

- Legacy decision:
- Why rejected:
- Simpler replacement:
- Review date:
- Owner:

## Rule

If a legacy behavior is not explicitly accepted in a mapping note, it is treated as rejected.
